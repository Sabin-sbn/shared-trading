# TRADING PROJECT — Sabin, Stefan & Nicolas

Proiect comun de trading: crypto, forex, stocks și orice tip de trading.

## Structură

- `Sabin_Logs/` — doar Sabin scrie aici (idei, implementări, probleme rezolvate, jurnale) — PERSONAL
- `Stefan_Logs/` — doar Stefan scrie aici — PERSONAL
- `Nicolas_Logs/` — doar Nicolas scrie aici — PERSONAL
- `Research/` — note de research comune (toți 3 pot adăuga)
- `Project_Board.md` — tabloul de sarcini comun (cine editează ce, status)
- `Chat.md` — discuțiile voastre (chat async)
- `START.bat` — dublu-clic pentru a deschide Chat.md direct în Obsidian (cu sync automat)
- `sync.bat` — dublu-clic pentru sincronizare (pull + commit + push + deschide folderul)
- `history.bat` — dublu-clic pentru istoric (cine a modificat ce și când)

## Reguli de aur

1. **Jurnalele personale: fiecare scrie doar în folderul lui.** Restul (board, research, chat) e comun — toți 3 pot modifica, iar Git ține evidența cine a schimbat ce (vezi `history.bat`).
2. `sync.bat` la fiecare sesiune de lucru (sau la terminarea unei tranzacții/analize).
3. Fișierele video NU se pun în Git → merg pe Google Drive partajat.
4. Nu editați niciodată același fișier în același timp (dacă se întâmplă: păstrați ambele părți și sync din nou).
5. Wikilink-urile `[[Nota]]` funcționează doar către notele din acest folder (nu către seifurile personale).
