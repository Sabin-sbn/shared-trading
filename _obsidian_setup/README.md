# Setare Graph View — Trading Project

Aceste fisiere sunt configuratia de Graph View, adaptata pentru
structura proiectului de Trading (3 persoane).

## Cum le instalezi (o singura data)

1. Copiaza `graph.json` in locul lui `.obsidian/graph.json` din vault-ul tau
   (in Obsidian: inchide Graph View-ul daca e deschis, copiaza, redeschide).
2. Copiaza `graph-view.css` in `.obsidian/snippets/graph-view.css`.
3. In Obsidian: Settings -> Appearance -> CSS snippets -> activeaza `graph-view`.
4. Deschide Graph View. Ai aceeasi "fizica" vizuala:
   - Research = galben, Stefan_Logs = albastru, Sabin_Logs = roz, Nicolas_Logs = cyan
   - tag-urile #todo / #crypto / #forex / #stocks au culorile lor

## Nota

- Aceste setari sunt doar vizuale — nu modifica niciun fisier de continut.
- Daca vrei alta culoare pentru o zona, editezi `colorGroups` din `graph.json`.
- `hideUnresolved: true` ascunde link-urile catre note inexistente.
